# XIAO ESP32-C3 同步带控制

`axis_c3_diagnostic/` 用于通过 PC 的 USB 串口识别控制板并读取光电开关输入。
`axis_c3_jog/` 是双板 USB 点动固件。屏幕端搭配 `panel_s3_jog`，PC 运行 `tools/run_usb_jog.py`。
开发板选 `esp32:esp32:XIAO_ESP32C3`，启用 `USB CDC On Boot`。

| 信号 | 板上丝印 | GPIO |
| --- | --- | --- |
| 驱动器使能 | D3 | 5 |
| 驱动器方向 `DIR` | D1 | 3 |
| 驱动器脉冲 `STP` | D2 | 4 |
| 负向限位 | D4 | 6 |
| 正向限位 | D10 | 10 |
| 原点 | D5 | 7 |

2026-11-20 按接线安排互换原点与正向限位：原点改为 D5 / GPIO7，正向限位改为 D10 / GPIO10。新版诊断固件已烧录到设备 `E4B323C6AB54` 并通过写入校验；三路实际触发与独立性仍需逐路验证。

诊断版把三个电机信号脚配置为输入，驱动器 24 V 关闭时进行诊断。三路开关输入启用上拉。串口返回的是原始 0/1 电平，开关未接时通常读为 1。

串口设置为 115200。每行发送一条如下所示的请求，以换行结束。诊断版接受此处列出的紧凑写法。

| 请求 | 回复 |
| --- | --- |
| `{"cmd":"HELLO"}` | `HELLO`、角色 `AXIS_C3`、唯一设备 ID、协议版本 `1`、固件名 |
| `{"cmd":"STATUS"}` | `LOCKED`、`motion_available: false`、零生成脉冲、三路原始输入及对应 GPIO 编号 |

## 当前现场版本（2026-11-23，协议 4）

根据现场测试反馈，当前正式构建暂时禁用自动寻零命令与 USR1+USR2 长按入口（`AxisControl.h` 中 `HOMING_ENABLED=false`）。仅测试构建显式启用保留的自动寻零代码。普通点动仍是 20 Hz 起步、2 秒升到 6827 Hz，按住持续运行，松手停止，目标约 80 mm/s。

### 端部限位停机锁定

任一端部限位新触发时，C3 本地立即停止发脉冲、禁用驱动并锁定两个方向，显示 NEG END STOP 或 POS END STOP；未经确认，解除输入后再按方向键也不会恢复。

单端停机后只需长按 USR3 约 1 秒一次：确认并进入等待松键，全部按键松开后即解锁，无需第二次长按。即使该端仍触发也可确认。解锁后只允许反向低速退出，最高 200 Hz；D4 负端用 USR1，D10 正端用 USR2，屏幕分别显示 ESCAPE: U1 FWD / ESCAPE: U2 REV。限位未解除时累计上限仍为 400 脉冲或 3 秒有效运行时间，松手不刷新预算。原端输入连续解除 20 ms、确实输出过退离脉冲后，立即结束退离限制；即使方向键一直按住，也重新按 2 秒曲线加速到普通速度，同时结束 STEP 定时器的旧预算，不再因已解除的旧记录达到 400 脉冲而停止。即使确认前已解除输入，首次仍须朝反方向实际退出。

双端同时有效、退离预算耗尽等故障仍需解除相应条件后确认；定时器故障不接受按钮强行清除。STEP ISR 平时检查任一端限位；只有已经确认的原端允许受限反向退出，新触发另一端或重新触发都再次停机锁定。

### D5 经过原点校零，运动不中断

D5 / GPIO7 的有效下降沿由 GPIO ISR 锁存当时 STEP 有符号计数。无故障的手动模式下，低电平经约 2 ms 确认后采用该边沿作为零点参考，不停止点动、不清累计 fwd/back/total。必须解除为高电平至少 20 ms 才重新接受下一次下降沿，避免同一次持续遮挡反复校零。

位置回报为当前 STEP 位置减去边沿捕获值；高速运动时屏幕可能越过正好 0 的瞬间，下一帧会继续显示离开零点后的位移。停着触发时位置会保持 0。界面显示 ORIGIN ZERO，`zeroed=1`；`zero` 是已接受的校零次数。`homed` 仍表示自动寻零完成，当前关闭自动入口时不会因此变成 1。这是手动经过传感器的参考校准，不是自动搜索回零或机械重复性验收。相反方向进入可能对应遮挡区的不同边沿。

端部停机、USR3 确认和链路超时锁定均保留原点参考与软件坐标，不再切换到上电坐标造成数值跳变。C3 重启后计数与参考重新建立；重新经过 D5 可再次校准。坐标仍只是 STEP 计数估算，不能检测停机期间的机械滑移。当前未开放绝对目标运动。

C3、S3 与 PC 均需配套使用协议 4，新增加 `zeroed` 和 `zero`，故障原因增加负端/正端停机。2026-11-23 根据现场反馈修复坐标跳变、退离清除和单次 USR3 解锁；离线 11 组 C++ 与 4 组 PC 协议测试通过。实时测试记录位于 `work/usb-trial-20261123/`。当前验证保持驱动器 24 V 关闭，不能将脉冲测试当作机械运动验收。

### 实体按键

| 当前状态 | 操作 | 结果 |
| --- | --- | --- |
| 锁定 | 长按 USR3 至 RELEASE USR3，再松开 | 解锁为 READY |
| READY / 点动 | USR1 正向、USR2 反向，按住运行 | 松手停止，USR3 停止并锁定 |
| 输入/回零故障 | 先解除两端限位，再长按 USR3 约 1 秒 | 确认故障；松开后保持锁定，不会同一次长按自动解锁 |
| 故障已确认 | 松开全部按键，再次长按 USR3 | 单独解锁 |
| 定时器故障 | 屏幕显示 RESTART REQUIRED | 不接受按钮清故障，需检查并重启控制板 |
| 锁定 | 同时长按 USR1 + USR2，至 RELEASE FOR HOME，再松开全部按键 | 发起独立低速回零 |
| 回零中 | 按 USR3 或任意方向键 | 立即取消并锁定；没有回零成功标记 |

锁定时逐路查看输入不会积累到位记录。就绪状态先后触发两端时，当前单端输入替代上一端历史，不再仅因历史按位累加而判双端故障；两端同时有效仍停机锁定。限位解除滤波为 20 ms，实际 STEP 上升沿前仍检查对应物理输入。

退离最高 200 Hz，累计最多 400 脉冲或 3000 ms **运动指令有效时间**；松手暂停不累计运行时间，也不刷新已用脉冲预算。原点开关可以处于触发状态，不阻止端部故障确认。屏幕显示具体故障原因，故障/锁定/松键提示优先于退离说明。

### 回零流程和预算

用户确认：原点位于两端限位之间、原点两侧各约 800 mm，总行程约 1600 mm；优先向负向（USR2）找原点。

- 正常从正向侧开始：负向低速搜索原点、停止并确认、向正向退离到输入解除、再次负向低速接近同一边沿，成功后建立坐标零点。
- 已在原点：先正向退离，再执行上述搜索和慢速复现。
- 从负向侧开始：若先到负端，STEP 会被本地限位停止；最多一次低速退出该端，再正向寻找原点。找到后仍向正向退出，最终统一负向慢速接近，避免两侧进入使用不同边沿。
- 从某一端起步：先进行该端受限低速退离，再向行程内部搜索。
- 若出现另一端、输入不稳定、阶段超时或脉冲预算耗尽，停止并报告原因，不建立零点。
- 成功后显示 HOMED ZERO，驱动停止、控制保持锁定；必须另行解锁才可手动点动。`pos` 使用回零参考偏移，累计 fwd/back 不清除。
- 链路超时取消回零并使参考失效；重连不会恢复运动。再次发起回零、取消或故障都不会保留一个虚假的回零成功状态。

| 阶段 | 目标频率 | 脉冲上限 | 阶段超时 |
| --- | --- | --- | --- |
| 寻找原点 | 200 Hz | 136534（约 1600 mm） | 720000 ms |
| 原点初始退离 / 搜索后退离 | 200 Hz | 800（约 9.375 mm） | 10000 ms |
| 最终统一负向接近 | 50 Hz | 1600（约 18.75 mm） | 40000 ms |
| 端部退出 | 200 Hz | 400（约 4.69 mm） | 3000 ms |

每次阶段切换有 500 ms 停稳/方向等待。输入匹配须稳定 20 ms；中断捕获边沿后最多等待 250 ms 取得稳定状态。回零期间 GPIO 原点边沿也由 STEP 定时器在上升沿前检查，输入瞬态不会直接宣告成功。最多两次有界搜索，不会无限来回寻找。

上述距离基于 37.5 mm/转、3200 脉冲/转和用户估计，仍需现场验证。200 Hz 约 2.34 mm/s，完整 1600 mm 搜索可能需要约 11 分钟。它是首次回零的低速配置，没有改变普通点动的 80 mm/s 目标。未添加编号绝对目标运动，未把估算行程当作已标定软限位。

验证普通持续点动时显式加 `--normal-jog --raw 7 --expect move --seconds 5`：测试要求持续按住超过 3 秒仍在运行、目标频率达到 6827 Hz 且新增脉冲超过 400。普通点动的脉冲预算与 `AxisJogProfile.h` 配置同步，`HoldToRun` 模式向 STEP 定时器提供无固定脉冲上限的预算；退离仍使用 `AxisLimits` 的独立预算。
